## Verified in this environment

The automated suites cover authentication/onboarding through the browser; database organisation and role boundaries; property/tenancy creation; rent allocation/idempotency; private and selectively shared repairs; revocation and attachment access; comments/status/notifications; compliance reminders and replacement history; deposit bounds, co-tenant response privacy and proposal concurrency; printable receipt permissions; property financial permissions and safe room archiving; persisted financial reports; import validation/commit; future rent changes; quota concurrency; and rejection of development subscriptions in production.

Browser tests use real local PostgreSQL records and exercise landlord and tenant journeys, including photograph upload, invitation activation, property records, repair feedback/responses, document previews/revocation, printable receipts, private deposit responses and mobile navigation. Provider-dependent services have not been tested with real accounts. See the final verification log/PR description for the counts from the latest run; the test sources remain the source of truth.

## Implemented interfaces, unavailable providers

Stripe Billing, Resend and private S3 storage require the operator's real/test credentials and service setup. No credentials were supplied for this task, so no remote transaction, delivery or storage claim is made.

Rent collection/Direct Debit, external signing, referencing/identity, Open Banking, Xero, deposit scheme confirmation, Rightmove/Zoopla, HMRC/MTD, credit rent reporting, sensors, document extraction and inventory analysis are unconfigured adapter contracts, **not completed integrations**. Essential manual ledger, files, repairs, expenses, compliance and deposit records function independently.

## Work still required to fulfil the entire brief

- Property-specific welcome guides, insurance attachment organisation and a more comprehensive property history search/export.
- Full digital tenant applications with employment/guarantor inputs, applicant files, holding deposits, viewing calendar and application-to-tenancy conversion. Current applicant acceptance creates a tenant record; tenancy creation is a separate supported workflow.
- Rent schedule edits for frequency/due-date changes, payment arrangements, structured adjustments/reversals and customisable receipt templates and a regulated online collection provider.
- Supplier/invoice receipt links directly on expense entries, itemised repair quotations and more advanced repair sorting/report dimensions.
- Document version replacement, editable correspondence templates, signatures, message attachments and full announcement workflows.
- Important property notices/welcome guides, additional tenant account controls and per-deduction deposit negotiation. Tenant proposal responses are private, immutable recorded positions; they do not automatically approve deductions or transfer funds.
- Detailed inventory video/meter/key evidence workflows, portable inspections, signed acknowledgments and full move-out settlement automation. Transition tasks/checklists and status updates work, but checklist completion does not automatically settle deposits or end a tenancy.
- Recurring accounting expenses, full bank statement matching/import reconciliation, mortgage/refinancing/hold-versus-sell scenarios, owner statement history and every requested report/filter/export type.
- Expanded maintenance spending/repeated-fault rules, more anomaly thresholds/severities, reminder schedules beyond configurable compliance/document lead times and complaint escalation. Review decisions are persisted; not all alert types are implemented.
- A complete portable rental passport with verified platform histories, external consent-scoped sharing links, references, tenant data exports and inter-organisation portability. Current free-form entries are self-reported; opted-in exports can include labelled manual tenancy ledger records. No credit scores or tenant ratings are generated.
- Import correction/rollback UI after commit, bank CSV import, bulk upload, tolerant quoted-header field mapping and cross-spreadsheet natural-key reconciliation. Current imports are bounded, validate a preview, commit atomically and never overwrite existing records.
- Organisation defaults/timezone/currency editing, configurable data-retention/deletion processing, fine-grained administrator support escalation, richer platform health metrics and plan/rule editing interfaces (update API exists for plans; compliance changes are new versions).
- Independently reviewed legal policies/compliance rules, penetration testing, accessibility audit, production provider verification, backup/restore drills, load/performance testing and launch operational procedures.

No contractor roles or AI assistant interface should be added as part of completing this version. Optional analysis must retain manual alternatives.

## Database changes in the latest operations update

Run `npm run db:migrate` against the configured database before running the updated application. Two additive migrations introduce private repair estimates and append-only deposit responses, including same-organisation foreign keys and idempotency constraints. Existing repairs and deposits remain intact. Production configuration and provider verification are separate operator steps; this update does not provision or deploy services.
